# Council members

This is the portable Agent Skills entrypoint for `llm-council:members`. Read the sibling [llm-council skill](../llm-council/SKILL.md), then run its `members` command using a trusted caller session ID or a user-chosen session label. Show the chosen model and effort selectors. Pass the same session ID to subsequent council calls. Do not change repository or user defaults for a session-only request.
